# CookieOS Research Kernel (CRK)

**CookieOS Research Kernel** is a kernel research project focused on operating system development, low-level programming, and kernel experimentation.

## About

CRK is being developed as part of the CookieOS project family. Its purpose is to provide a codebase for researching kernel internals, experimenting with system-level features, and developing operating system components.

## Project Goals

- Explore kernel architecture and internal subsystems.
- Experiment with low-level hardware interaction.
- Develop memory management and process management.
- Research device drivers and interrupt handling.
- Build and test kernel components in a controlled environment.
- Establish a maintainable and extensible source tree.

## Development

CRK is under active development. Features, architecture, build requirements, and boot procedures will be documented as the project evolves.
